# DotnetDllParser

Простой инструмент для декомпиляции указанных "важных" .NET DLL сборок в читаемый C# код.

## Описание

Этот инструмент сканирует указанную директорию на наличие DLL файлов, декомпилирует определенные сборки (список "важных" библиотек задан в коде) и сохраняет результат в виде текстовых файлов (`.cstxt`).

Для предотвращения создания слишком больших файлов, код для каждой сборки разбивается на "чанки" (куски) размером примерно 950 КБ. Каждый чанк сохраняется как отдельный файл (`ИмяСборки_chunkN.cstxt`) внутри поддиректории, названной по имени исходной сборки.

## Использование

Проект можно запустить напрямую с помощью .NET SDK:

```bash
dotnet run -- -s <путь_к_исходным_dll> -o <путь_к_выходной_директории>
```

### Параметры

*   `-s`, `--source` (обязательный): Путь к директории, содержащей DLL файлы для анализа.
*   `-o`, `--output` (обязательный): Путь к директории, куда будут сохраняться декомпилированные файлы (внутри будут созданы поддиректории для каждой обработанной DLL).

### Пример

```bash
dotnet run -- -s /home/user/rust-template/Managed -o /home/user/rust-template/.knowlenge/Decompiled
```

Эта команда обработает DLL из `/home/user/rust-template/Managed` и сохранит декомпилированный код в поддиректориях внутри `/home/user/rust-template/.knowlenge/Decompiled`. Например, чанки для `Assembly-CSharp.dll` будут находиться в `/home/user/rust-template/.knowlenge/Decompiled/Assembly-CSharp/`.
